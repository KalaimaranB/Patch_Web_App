## What is Patch Medical?

Patch Medical is a **caregiver monitoring dashboard** for patients using Patch Medical hardware medication-delivery devices. Once a device is set up and linked to your account, the dashboard shows you:

- When doses were administered and whether they were successful
- The current status of connected devices
- Historical dosage trends over any date range
- Real-time notifications when a dose event occurs

The dashboard is a **read-only monitoring tool** — it displays data sent by the physical device and does not control or trigger doses.

---

## Who is this for?

This dashboard is intended for **caregivers** — family members, healthcare aides, or clinicians — who are responsible for monitoring a patient's medication adherence. You do not need to be physically present with the patient; the dashboard works remotely as long as the device has a WiFi connection.

---

## Prerequisites

Before you can use the dashboard you need:

1. **A Patch Medical hardware device** — the ESP32-based dispenser that is set up near the patient.
2. **An account** — accounts are created through the device's setup portal (see [Registration]({% link user-guide/registration.md %})).
3. **A modern web browser** — Chrome, Firefox, Safari, or Edge. The app is fully responsive and works on mobile.

---

## Accessing the Dashboard

The dashboard is available at:

**[https://patch-web-app.vercel.app/login](https://patch-web-app.vercel.app/login)**

You do not need to install anything. Open the link in your browser, sign in, and the dashboard loads immediately.
